# Page Web R10.38 — confort de lecture

Cette révision ne modifie ni le firmware Arduino ni le protocole Web Serial.

## Changements

- Police système naturelle : Segoe UI sur Windows, SF Pro sur macOS, Arial/Helvetica en secours.
- Taille de texte générale portée à 17 px sur ordinateur, 16 px sur mobile.
- Titres, libellés, cartes de mesure, tableaux, formulaires et documentation agrandis.
- Interlignage et espacements augmentés pour améliorer la lecture prolongée.
- Menu, boutons et champs de configuration agrandis pour une utilisation tactile plus confortable.
- Cartes toujours compactes, mais valeurs et unités désormais plus faciles à lire.

L’interface reste entièrement locale et n’utilise aucune police ou ressource distante.
